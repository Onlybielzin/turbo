# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: Foundation — Tauri + PTY.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> **Scope note:** This phase is pure infrastructure. The only UI deliverable is a
> minimal app shell (header + single fullscreen xterm instance) that proves the
> PTY round-trip. No canvas, no node graph, no component library. This contract
> locks the foundational tokens that Phases 3 and 4 will inherit.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — plain CSS custom properties |
| Icon library | none in this phase |
| Font (UI shell) | `ui-sans-serif, system-ui, sans-serif` |
| Font (terminal) | `ui-monospace, "JetBrains Mono", "Fira Code", Menlo, monospace` |

**Rationale:** shadcn was skipped. This is a personal single-user Linux desktop
tool; the Phase 1 deliverable is a proof-of-concept shell, not a component
library surface. Plain CSS custom properties are sufficient and cheaper.

## Spacing Scale

Declared values (multiples of 4 only). Source: derived from existing `App.css`
values plus 8-point scale defaults.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tight inline padding |
| sm | 8px | Header padding (vertical: 8px, matches `.app-header` padding-block) |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (reserved for future phases) |

Exceptions:

- Header uses `padding: 8px 14px` (horizontal 14px is non-standard; lock it as a
  named exception: `--space-header-inline: 14px`). This value is already in the
  existing codebase and must not be normalised to 16px without a visual re-check.
- Brand mark: 22×22px circle — non-scale value locked from existing code.

## Interaction States

Phase 1 has no interactive UI controls beyond the terminal itself. xterm.js
handles all cursor, selection, and focus states internally. The app shell is
non-interactive (header is `user-select: none`).

| Element | State | Treatment |
|---------|-------|-----------|
| App header | static | No hover/focus states — `user-select: none` |
| Terminal host | focused | xterm cursor blink at `#c9433a` |
| Terminal host | output | Streams bytes — no UI state indication in Phase 1 |
| PTY exit event | terminal message | `\r\n\x1b[90m[process exited]\x1b[0m` (gray ANSI, already in code) |
| PTY spawn failure | terminal message | `\r\n[failed to start pty: {error}]` (plain text, already in code) |

---

## Copywriting Contract

Phase 1 has minimal copy. There is no user-facing empty state or CTA — the
terminal auto-spawns on mount.

| Element | Copy |
|---------|------|
| Brand name | `turbo` |
| Header subtitle | `canvas de agentes` |
| PTY exit message | `[process exited]` (rendered in ANSI gray via xterm) |
| PTY spawn failure | `[failed to start pty: {error description}]` |
| Primary CTA | none — no buttons in Phase 1 shell |
| Empty state | none — PTY auto-starts; no empty state |
| Destructive actions | none — no kill button in Phase 1 (TERM-04 is Phase 3) |

## Layout

| Area | Specification |
|------|---------------|
| App shell | `display: flex; flex-direction: column; height: 100vh` |
| Header | `height: auto; padding: 8px 14px; border-bottom: 1px solid var(--border)` |
| Terminal area | `flex: 1; min-height: 0; padding: 8px` — fills remaining viewport |
| Terminal host | `width: 100%; height: 100%` — xterm FitAddon resizes to container |

No scroll outside the terminal. The xterm instance owns its own scroll.

## xterm Configuration Contract

| Option | Value | Rationale |
|--------|-------|-----------|
| `fontFamily` | `ui-monospace, "JetBrains Mono", "Fira Code", Menlo, monospace` | Source: Terminal.tsx — already in code |
| `fontSize` | 13 | Source: Terminal.tsx — already in code |
| `cursorBlink` | `true` | Source: Terminal.tsx |
| `theme.background` | `#161514` (matches `--panel`) | Blends terminal into panel |
| `theme.foreground` | `#e6e1dc` (matches `--text`) | Consistent with UI text color |
| `theme.cursor` | `#c9433a` | Warm red cursor — distinct from text without clashing |
| Renderer | `CanvasAddon` (not WebGL) | Phase 1 only has one terminal; WebGL reserved for focused node in Phase 3 per TERM-02 |

## Phase Boundary Notes for Downstream Phases

These tokens are declared in Phase 1 and MUST be reused verbatim by Phases 3 and 4:

- CSS custom properties in `App.css` (`--bg`, `--panel`, `--border`, `--text`, `--muted`, `--brand-a`, `--brand-b`)
- Terminal font stack and font size (13px)
- xterm theme object (`background`, `foreground`, `cursor`)
- Canvas renderer as default; WebGL only for the focused node (TERM-02)

Phase 3 will introduce: `@xyflow/react` canvas, TerminalNode component, GroupFrame, status badge on node header. Those tokens are out of scope here.
