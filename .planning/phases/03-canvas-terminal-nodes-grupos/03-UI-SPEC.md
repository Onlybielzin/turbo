# Phase 3 — UI Design Contract

> Visual and interaction contract for Phase 3: Canvas + Terminal Nodes + Grupos.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> **Scope note:** This is the visual centrepiece of Turbo. The deliverable is an
> infinite pan/zoom canvas (@xyflow/react) where every node is a live xterm.js
> terminal (TerminalNode) and groups of related terminals are contained in
> GroupFrames. All foundational tokens from Phase 1 are inherited verbatim —
> this contract adds only the canvas-specific contracts Phase 1 did not cover.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — plain CSS custom properties (inherited from Phase 1) |
| Icon library | none — status indicators are CSS shapes / Unicode symbols |
| Font (UI shell) | `ui-sans-serif, system-ui, sans-serif` (inherited) |
| Font (terminal) | `ui-monospace, "JetBrains Mono", "Fira Code", Menlo, monospace` (inherited) |
| Canvas library | `@xyflow/react` 12.x — `dist/style.css` imported, then overridden |

**Rationale:** shadcn remains skipped. Personal single-user desktop tool. Plain CSS
custom properties already established in Phase 1 are extended here with new
canvas-specific tokens. No component library overhead is warranted.

## Typography

Inherited from Phase 1. Three sizes and two weights remain the ceiling.
Canvas adds one new role: the node label in the TerminalNode header.

| Role | Size | Weight | Line Height | Font Stack |
|------|------|--------|-------------|------------|
| Terminal output | 13px | n/a (monospace inherit) | xterm default (~1.2) | monospace stack |
| UI label / subtitle | 12px | 400 (regular) | 1.4 | sans-serif stack |
| UI body / default | 14px | 400 (regular) | 1.5 | sans-serif stack |
| Brand name | 14px | 700 (bold) | 1.0 | sans-serif stack |
| **Node label** | **12px** | **600 (semibold)** | **1.0** | sans-serif stack |
| **GroupFrame cwd** | **11px** | **400 (regular)** | **1.0** | monospace stack |

**New weight:** 600 (semibold) added for node labels — the only addition to Phase 1's
two weights (400, 700). Weights used in Phase 3: 400, 600, 700.

**Node label** (12px/600): displayed in the TerminalNode header bar — must be legible
at small canvas zoom levels. Semibold provides enough contrast against the gradient
background without becoming heavy.

**GroupFrame cwd** (11px/400, monospace): path string below the group label —
monospace chosen because it is a filesystem path. Truncated with `text-overflow: ellipsis`
from the right when too long.

- **60% `#0f0e0d`** — canvas background fills the viewport (infinite pan surface)
- **30% `#161514`** — node bodies, GroupFrame fills, node header non-gradient area
- **10% brand gradient `#9e2a1a → #5c160d`** — TerminalNode header bars only

1. TerminalNode header bar background (linear-gradient top→bottom)
2. Brand mark in the app header (inherited from Phase 1)

other interactive elements. Status colours (`--status-*`) are the only other hues
in the palette.

## Component Inventory

### TerminalNode

A custom `@xyflow/react` node rendered for every live PTY.

**Anatomy (top to bottom):**

```
┌─────────────────────────────────────────────┐  ← node frame, border: 1px --node-border
│ [●] label                             [×]   │  ← header: 32px, bg: gradient brand-a→brand-b
├─────────────────────────────────────────────┤
│                                             │
│            xterm.js canvas                 │  ← body: flex-1, bg: --panel
│                                             │
└─────────────────────────────────────────────┘
  └─ resize handle (SE corner, 8×8px)
```

**Header bar (32px fixed height):**

- Background: `linear-gradient(180deg, var(--brand-a), var(--brand-b))`
- Padding: `0 8px` (8px inline on both sides)
- Layout: `display: flex; align-items: center; gap: 4px`
- Left side: status dot (8×8px circle) + node label (12px/600)
- Right side: kill button (×), 24×24px tap target, icon is `×` at 14px/400
- `user-select: none`

**Status dot (8×8px, border-radius: 50%):**

| State | Color token | Meaning |
|-------|-------------|---------|
| running | `--status-running` (`#3a9e4a`) | Process alive |
| exited (ok) | `--status-ok` (`#5a8a6a`) | Exit code 0 |
| error | `--status-error` (`#c9433a`) | Non-zero exit |

No animation on the dot. Static fill colour is sufficient for a cockpit tool.

**Kill button (×):**

- Base: `background: transparent; border: none; color: rgba(255,255,255,0.7); cursor: pointer`
- Hover: `background: var(--kill-hover-bg); color: #fff; border-radius: 4px`
- Active: `opacity: 0.8`
- Tooltip: `title="Matar processo"` (native tooltip — no custom component)
- On click: kill PTY → emit `pty_kill` Tauri command → remove node from store

**Node body:**

- Background: `var(--panel)` (`#161514`)
- `padding: 0` — xterm fills flush to the body edges
- xterm instance fills 100% width and height of the body

**Node frame:**

- Default: `border: 1px solid var(--node-border)` + `border-radius: 6px`
- Focused (WebGL active): `border-color: var(--node-border-focused)` — no glow, just
  border lightening

**Resize handles:**

- @xyflow built-in `NodeResizer` component
- Visible only on node hover/focus
- Min size: 240×160px (prevents xterm from collapsing to unreadable size)
- No custom handle styling beyond ReactFlow defaults (matches dark theme)

**Default size on spawn:** 480×280px (body 280px minus 32px header = 248px terminal area;
≈80 cols × 24 rows at 13px font with FitAddon — confirmed by FitAddon.fit() on mount)

**Renderer switching:**

- Default: `@xterm/addon-canvas` (CanvasAddon)
- When node gains focus: detach CanvasAddon → attach WebGL addon
- When node loses focus: detach WebGL → reattach CanvasAddon
- Transition is synchronous — no fade animation; terminal content is preserved
- At most 1 WebGL context active at any time

### GroupFrame

A custom `@xyflow/react` node of type `group` that acts as a visual container for
TerminalNodes spawned in the same project directory.

**Anatomy:**

```
┌── GroupFrame ─────────────────────────────────┐  ← containment border 1px --group-border
│ [label]  /path/to/cwd              [+ Novo]   │  ← label bar 28px, bg: --panel
├───────────────────────────────────────────────┤
│                                               │
│   TerminalNode  TerminalNode  ...             │  ← inner canvas, bg: --group-bg
│                                               │
└───────────────────────────────────────────────┘
```

**Label bar (28px fixed height):**

- Background: `var(--panel)` (`#161514`)
- Border-bottom: `1px solid var(--group-border)`
- Padding: `0 12px`
- Layout: `display: flex; align-items: center; gap: 8px`
- Left: group label text (14px/400, `--text`) — editable on double-click (inline `contenteditable`)
- Middle (flex-1): cwd path (11px/400, `--muted`, monospace, `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`)
- Right: "+ Novo terminal" button (12px/400, `--muted`) — visible on label bar hover only

**Frame body:**

- Background: `var(--group-bg)` (`rgba(22, 21, 20, 0.55)`)
- Child TerminalNodes use `parentId` + `extent: 'parent'` to stay contained
- Padding inside frame (gap from frame border to child node): 32px (`--xl`)

**Frame border:**

- `border: 1px solid var(--group-border)` + `border-radius: 8px`
- No hover state on the frame itself — hover is on its children

**Default size on creation:** 800×600px — large enough to accommodate 1 TerminalNode
at default size (480×280px) plus the 32px inner padding on all sides.

**Group label:**

- Default on creation: `Grupo {n}` where n is 1-indexed creation order
- Editable by double-clicking the label text (inline contenteditable, 1-field edit)
- On blur or Enter: commit label; Escape: revert

### Toolbar ("Novo grupo" action)

A fixed-position overlay anchored to the top-left of the canvas viewport (not in the
flow coordinate space — sits above the ReactFlow container).

**Position:** `position: absolute; top: 8px; left: 8px; z-index: 10`

**"Novo grupo" button:**

- Size: `height: 28px; padding: 0 12px`
- Background: `var(--panel)` base, `var(--border)` on hover
- Border: `1px solid var(--border)` — `border-radius: 4px`
- Text: `"+ Novo grupo"` — 12px/400, `--text`
- Cursor: pointer
- On click: open Tauri native directory picker → create GroupFrame + auto-launch `claude` node

**No other toolbar items in Phase 3.** The ReactFlow `<Controls>` component (zoom in/out,
fit view) is rendered at bottom-right (ReactFlow default position) with dark background
overrides matching `--panel`.

## Interaction States

### TerminalNode

| Interaction | Treatment |
|-------------|-----------|
| Hover (node, not header) | `border-color` lightens 10% — no glow ring |
| Drag (moving node) | ReactFlow default ghost cursor; node opacity 0.85 during drag |
| Focus (click into terminal area) | Border switches to `--node-border-focused`; WebGL renderer activates |
| Blur (click outside) | Border returns to `--node-border`; Canvas renderer restores |
| Kill (click ×) | Process killed; node fades out (`opacity: 0 → remove` in 150ms); no confirmation |
| Status change running→ok | Status dot transitions from green to dim-green (no animation — immediate) |
| Status change running→error | Status dot transitions to `--status-error` red (no animation — immediate) |

### GroupFrame

| Interaction | Treatment |
|-------------|-----------|
| Hover (frame background, not child) | Label bar "+ Novo terminal" button becomes visible |
| Drag (moving frame) | Moves all contained children together (ReactFlow group behaviour) |
| Resize (frame handles) | Extend/contract frame; child nodes constrained by `extent:'parent'` stay inside |
| Double-click label | Inline contenteditable activates on label text |
| Label blur/Enter | Commit new label; return to static display |
| Label Escape | Discard edit; revert to previous label |

### Canvas

| Interaction | Treatment |
|-------------|-----------|
| Pan | Drag on empty canvas area — ReactFlow default (mouse + touchpad) |
| Zoom | Scroll wheel — ReactFlow default (Ctrl+scroll on Linux) |
| Fit view | Ctrl+Shift+H — ReactFlow default keyboard shortcut |
| Multi-select | Shift+drag marquee — ReactFlow default |
| Empty canvas | Show centred empty state (see Copywriting Contract) |

## xterm Configuration Contract

All values inherited from Phase 1. Repeated here for executor convenience:

| Option | Value |
|--------|-------|
| `fontFamily` | `ui-monospace, "JetBrains Mono", "Fira Code", Menlo, monospace` |
| `fontSize` | 13 |
| `cursorBlink` | `true` |
| `theme.background` | `#161514` |
| `theme.foreground` | `#e6e1dc` |
| `theme.cursor` | `#c9433a` |
| `scrollback` | 1000 (default) |
| Default renderer | `CanvasAddon` (not WebGL) |
| Focused renderer | `WebGLAddon` (only 1 active at a time) |

**FitAddon behaviour:** debounced 16ms on ResizeObserver callback (matches Phase 1
pattern). Called once on TerminalNode mount after renderer is attached.

**xterm inside CSS transform:** ReactFlow applies a CSS `transform: scale()` to the
canvas viewport during zoom. FitAddon must read `offsetWidth`/`offsetHeight` of the
terminal container — not `getBoundingClientRect()` — to get pre-transform dimensions.
This avoids cols/rows being wrong at zoom levels other than 1.0. This is a known
pitfall from PITFALLS.md and must be implemented correctly in `usePty`.

## Performance Constraints

These are visual contracts that affect render architecture decisions:

| Constraint | Contract |
|------------|---------|
| WebGL contexts | Maximum 1 active at any time. All unfocused nodes use CanvasAddon. |
| Re-render | `React.memo` on TerminalNode. Zustand selector scoped to `node.id` — a status change on node A must not re-render node B. |
| FitAddon | Debounced 16ms on ResizeObserver. Never called synchronously during zoom (xterm inside CSS transform). |
| Target | 15 simultaneous TerminalNodes with pan/zoom fluidity. No visible jank. |
