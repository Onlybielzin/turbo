# Phase quick-260806-g39 Plan 01: Worktrees Summary

Suporte a múltiplas git worktrees por grupo no Turbo: detectar worktrees existentes, criar novas, rotear cwd por raia no GroupFrame, garantir `.mcp.json` dentro de cada worktree que hospeda agente, e fazer `spawn_agent` herdar a worktree do pai.

| 3 | Raias por worktree no GroupFrame | aa4f333 | store.ts, GroupFrame.tsx, GroupFrame.css |

## What Was Built

**Rust (Task 1):**
- `worktrees.rs`: módulo novo com `list_worktrees`, `create_worktree`, `ensure_worktree_mcp`
- `list_worktrees`: chama `git -C <cwd> worktree list --porcelain`, faz parse bloco-a-bloco (suporta detached HEAD, retorna `Ok(vec![])` se não for repo git)
- `create_worktree`: valida `name` via regex `[A-Za-z0-9._-]` (rejeita `/`, `..`, espaços), cria `.claude/worktrees/<name>`, chama `git worktree add` com ou sem `-b`
- `ensure_worktree_mcp`: delega para `write_mcp_json` — garante `.mcp.json` idempotente dentro da worktree
- `groups.rs`: extrai `write_mcp_json` como `pub fn` com assinatura `(cwd: &Path, group_id: &str, mcp_port: u16) -> Result<String, String>`; `GroupRegistry::register` chama-a em vez de duplicar o JSON
- `lib.rs`: adiciona `mod worktrees` e registra os 3 comandos no `invoke_handler`

**Rust (Task 2):**
- `server.rs` `SpawnParams`: novo campo `#[serde(default)] pub worktree: String`
- `spawn_agent`: computa `cwd = if p.worktree.trim().is_empty() { None } else { Some(...) }`, passa para `run_in_pty_blocking`; propaga `TURBO_WORKTREE_CWD` no `extra_env` do filho quando não vazio

**TypeScript (Task 3):**
- `store.ts`: `TerminalNodeData.worktree?: string`; `GroupNodeData.{worktrees?, activeWorktree?}`; tipo `Worktree` exportado; `addTerminalNode` recebe `worktree?` como 9º param; ações `setGroupWorktrees` e `setActiveWorktree` (imutáveis)
- `GroupFrame.tsx`: `useEffect` com cleanup que chama `list_worktrees` no mount; `handleCreateWorktree` com `window.prompt` + `create_worktree` + re-lista; barra de raias com chips; `openTerminal` usa `wtPath = activeWorktree ?? cwd` e injeta `TURBO_WORKTREE_CWD`
- `GroupFrame.css`: `.group-frame__lanes`, `.group-frame__lane`, `.is-active`, `.group-frame__lane-add` — barra 28px, chips monospace 10px, ativa com accent + color-mix glow
